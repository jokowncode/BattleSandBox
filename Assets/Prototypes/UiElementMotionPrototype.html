UI 微动效组件库

每张卡都可独立重播。目标不是让 UI 一直动，而是在出现、确认、数值变化和警示这些“有意义的瞬间”给出短促反馈。

01 / 直接出现

适合常驻 HUD；只给一次亮度确认。

02 / 淡入上浮

适合战斗准备、次级操作组。

03 / 左侧飞入

适合侧栏、任务提示中的新按钮。

04 / 缩放弹出

适合高优先级确认，但不应大量使用。

05 / 弹性落位

适合战利品确认、强奖励操作。

06 / 扫光与退出

扫光表示可操作；退出适合一次性 CTA。
